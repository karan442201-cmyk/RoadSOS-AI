# Team Division

## Backend Developer

- Own FastAPI endpoints in `backend/`.
- Add SQLite persistence using `database/schema.sql`.
- Connect SMS, email, or WhatsApp SOS notification providers.

## UI / Frontend Developer

- Own `frontend/index.html`, `frontend/styles.css`, and `frontend/app.js`.
- Improve mobile navigation, visual polish, and demo flows.
- Add real Maps JavaScript API when a key is available.

## Core Logic / AI Developer

- Own `ai_logic/intent.py` and `ai_logic/routing.py`.
- Add Gemini API fallback while preserving offline rule-based responses.
- Tune emergency classification and routing decisions.
